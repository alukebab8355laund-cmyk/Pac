## 📖 О проекте

**PAC (Pictures Assembly Compiler)** — это уникальный инструмент, который позволяет создавать PNG-изображения, описывая каждый пиксель, линию или фигуру простым текстовым кодом. 

Вдохновлён философией ассемблера: **максимальный контроль на уровне каждого пикселя**.

### 💡 Почему PAC?

- 🎯 **Точность** — контролируешь каждый пиксель вручную
- 📝 **Текстовый формат** — легко версионировать в Git
- 🤖 **Автоматизация** — скрипты могут генерировать графику
- 📦 **Без зависимостей** — чистый Python 3
- 📱 **Работает на телефоне** — оптимизирован для Termux

## ⚡ Возможности

### 🎨 Графические примитивы

| Команда | Описание | Статус |
|---------|----------|--------|
| `/1px` | Один пиксель | ✅ Работает |
| `/rect` | Прямоугольник | ✅ Работает |
| `/line` | Линия (алгоритм Брезенхэма) | ✅ Работает |
| `/circle` | Круг | 🔄 В разработке |
| `/fill` | Заливка области | 🔄 В разработке |
| `/gradient` | Градиент | 🔄 В разработке |

### 🎯 Управление холстом

| Команда | Описание |
|---------|----------|
| `/size Ш В` | Установить размер холста |
| `/bg #ЦВЕТ` | Цвет фона |
| `/save имя.png` | Имя выходного файла |

### 📦 Архитектура

- **20 модулей расширения** в папке `modules/`
- **60 бинарных заглушек** в папке `GEN/` (~1 МБ каждый)
- **Модульная система** — легко добавлять новые функции
- **Поддержка 6 000 000+ пикселей** на холст

## 🛠️ Установка

### Вариант 1: Из архива (рекомендуется)

```bash
# Скачай PAC_System.tgz

cd pac_system

# Дай доступ к памяти телефона

chmod +x lib/pac.py

# (Опционально) Скопируй в домашнюю папку
